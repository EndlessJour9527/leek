# E4 国内股票ETF动量研究：收益运行前注册 v1.0

登记日：2026-10-18 UTC。状态：DESIGN_FROZEN / DATA_BLOCKED。仅模拟研究，无实盘委托。旧V1、旧30组结果及现站不得覆盖。

## 1. 问题与冻结池
检验一个狭窄问题：在固定的境内股票ETF风格/规模池内，中期相对强弱能否在成本后改善相同股票预算的静态等权配置。信息缓慢反映与风格延续只是可证伪经济假设；排名也可能仅放大高波动或行业暴露。海外个股/多资产动量论文不是这四只中国ETF的有效性证明。

固定四只：510300（沪深300，大盘）、510500（中证500，规模序列中相对中盘，其官方名称仍为中证小盘500）、512100（中证1000，较小市值）、159915（创业板，上市板块成长暴露）。每类一个既有产品，不按2021—2026收益、当前规模或回测排名选取。代码固定为可审计案例，不宣称完整市场最优或无幸存者偏差；要消除幸存者偏差仍需2020时点全产品含退市清盘清单。不得删掉表现差或数据难的品种，也不得用510050替代缺失品种。

前三类指数设计有规模层次；创业板与它们可能有成份重叠及共同科技行业暴露，绝非四个独立风险源。只能称“股票内部分散”；不能称跨资产、充分分散或风险已分散。报告历史可得的成份/行业交集、滚动相关与权重集中度，但这些只作解释，不能据此临时换池。511010、518880、QDII、杠杆/反向产品、行业热点池均不属于本批。

## 3. 信号与日期（精确定义）
令m为信号所在的完整自然月，E(m)为当月最后一个交易所交易日的已知收盘总回报指数；12-1得分为TR[E(m-1)] / TR[E(m-12)] - 1，6-1为TR[E(m-1)] / TR[E(m-6)] - 1。即排除刚结束的m月，不使用未来复权回填。相同得分按六位代码升序；比较用未展示舍入值，数值差≤1e-12才视同分。

主窗固定2021-10-18至2026-10-16，账户连续，不年度清零、不期末清仓。首次信号在2021-10-15收盘制定，采用最近完整月2021-09的排名：12-1端点2021-08-31与2020-09-30；初始份数采用2021-10-15原始收盘价和账户NAV。其后每个自然月最后交易日收盘产生排名和份额计划，次交易日开盘代理交易。最后信号若无样本内下一日，不交易。必须具备2020-09-30至截止日的原始价格及全部公司行动证据（建议抓取从2020-09-01）。

预先规定唯一短窗降级：若全池2020历史无法补齐、但全池自2021-01-04起完整合格，改为2022-02首交易日开始执行至2026-10-16，首个形成月2022-01，M12端点2021-12月末/2021-01月末。此为不足五年、全组同时降级；不能将M6较早开始或不同品种各自起点结果作主比较。若这个共同窗也缺证据，保持BLOCKED。必须在任何收益运行前记录选择了主窗或该唯一降级窗并哈希冻结。

另一种证据受限情形预登记唯一合格前缀：若2020预热齐全但2026H2公司行动只有不足以接受的证据，允许同一账户从主起点执行至2026-06-30，明确标为PREFIX_ONLY，保留2026-07-01—10-16为待核，不允许宣布主窗G2通过或完整五年结果。补齐H2后延伸同一账户，先核前缀不变；不是新的择优起点。主起点短窗降级与H1前缀可同时适用，但必须在收益前记录共同窗口。

历史分段只作稳定性描述：2021-10-18—2022-12-30、2023-01首交易日—2024-12末交易日、2025-01首交易日—2026-10-16（短窗第一段相应截短）。近五年都已被查看，所有这些段均为已接触开发数据，不称盲测、未见测试、样本外证明。未来前瞻实验须在实际首个有效月末前另冻结数据/代码哈希，最早2026-10月末形成信号，最早2026-11首交易日开始；不能回填已经过去的执行日。

## 4. 数据与总回报契约
每只原始OHLC、交易所交易日、停牌/复牌及涨跌幅制度按日期核验；异常缺行必须解释，不能插值成可成交报价。停牌日为估值可延用最近有效收盘并标stale；不得成交；月末停牌可用带stale标识估值排名（只要停牌官方证据齐），必须报所有此类信号。无法解释的缺价使整个数据门失败。

总回报信号按除权日向前链式构造，现金分红及拆合份额只在生效时进入。公告发布时间须早于应用时点；未来已公告事件不能提前改历史TR或计划持仓。原始价格用于成交及市值，不能把复权价用于买卖。公司行动必须有公告日、登记日、除权日、支付日、每份现金、精确比例及适用税务证据；“没有抓到公告”不能当无事件。

512100官方合并公告已在预检核到：2022-09-01登记，2022-09-02按0.36555新份/旧份合并并停牌，2022-09-05复牌；账户新份额按公告向上进位至整数份。信号TR只应用理论精确比例0.36555，不把账户ceil导致的舍入增益写入排名；实际账户份额ceil(旧份额*0.36555)，总成本基数保持不变（有现金补偿则按官方规则），份额舍入带来的NAV差单独列账，不伪称财富完全不变。后续仍须全区间CA核对与独立用例。159915于2021-02-08缺行已有停牌公告线索，须保存官方/管理人原文并区分停牌与数据丢失。

## 5. 交易、预算及成本
共同规则：100份整手买卖、股票ETF T+1；不以当天成交量、高低收盘决定当日开盘下单。手续费和滑点是保守实验假设，不代表真实券商报价；基金内含管理/托管费已在价格/NAV中，不再重复扣。
- base：单边佣金10bp，最低5元；不利滑点10bp。
- double：单边佣金20bp，最低10元；不利滑点20bp。
- severe：单边佣金20bp，最低10元；不利滑点30bp。
每档重新计算份额/现金/成交；不把旧成交事后减成本。无印花税/扣税必须有该品种适用规则证据才作为数据闸门通过；无证据则标阻塞，不臆造税率。

信号日收盘NAV含应收分红，目标份数 floor(weight * NAV / raw_close / 100) * 100；按持仓差额制定卖/买数量。现金不是目标股数；应收款不是可用现金。计划买数只可减、不能因次日价低增量。执行开盘已生效拆合并只做机械份额转换和合法整手取整，不能重新按未来信息优化目标；若转换规则未验证则拒绝该日全部订单并记录。

先执行合格卖单（代码升序），只使用实际卖出收入与实际可用现金。相同开盘先卖后买的可用资金是假设性日频代理，不声称已证实竞价原子调仓；必须在报告披露。买单先按每只不超过原计划数量、signal-day计划名义金额和自身目标权重对应的signal NAV金额三重上限限制，再以成交价（含滑点）计算。若加佣金后买单合计超过现金，把所有买单按同一个可负担系数缩小并100份向下取整；系数取[0,1]内满足实际最低佣金的最大值，剩余现金不作补配。不存在按买单排序偏向某ETF。

无正数open、已知停牌、买入触及适用涨停/卖出触及跌停均拒绝该侧订单。涨跌停制度必须按ETF和日期区分（159915不可套旧引擎全池10%）。开盘参考价/tick/限价四舍五入必须有源；没有历史竞价/订单簿时永远保留“条件性日频开盘代理”证据标签。拒单day-only，当日不补、次日不追；直到下个月正常信号再算；不追赶新排名或替补第三名。

登记日收盘份额确定分红资格，除息生成应收，支付日现金到账一次。主假设支付日收盘后才可用，下一交易日开盘可用；这比旧批盘前可用假设更保守。另做仅会计时点审计：若官方证明盘前到账，列出影响订单日期及最大资金差，不据此切换主路径。零头和合并精度按官方登记规则处理；不能自行截断财富。若官方允许剩余零头一次性清仓，可在目标0时连同整手卖出；若无法核实，保持整手减仓、零头保留估值，披露残余暴露且执行真实性闸门不通过。不得用浮点误差创造资金。
