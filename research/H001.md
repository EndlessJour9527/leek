# H001：MA120 连续 3 个交易日确认（冻结研究假设）

状态：**UNVALIDATED / PAPER_RESEARCH_ONLY**。目前没有可验收的真实历史收益、胜率或最大回撤结果。

## 假设与对照
与当前 MA120 趋势研究规则（确认数 1）相比，MA120 连续 3 个已收盘交易日确认方向，能否减少震荡反复交易的净成本，且改善幅度大于延迟进出场带来的损失？

冻结参数：lookback=120，确认期=3。对照确认期=1；其余证券池、交易日、投资比例、风险上限、交易时点、佣金、滑点、分红/复权及可成交性模型完全一致，不能事后更改参数称为同一个实验。

高于含当日收盘的 MA120 连续三日 => 研究状态 ON；低于连续三日 => OFF；等于 MA120 时重置计数但保持先前状态。初始 OFF。信号收盘后才可产生，最早下一可交易时点才允许模拟执行，不得用当日收盘价假设成交。ON 不等于真实账户买入指令，也不指定仓位。

## 评价和晋级
对照和候选需各自使用连续承接现金、持仓及费用的账户，报告净收益、最大回撤、持仓敞口、换手、费用、已平仓样本及市场分段表现，设置独立封存测试与前向纸面验证。暂停原因及不成交必须保留。原始价用于模拟成交；时点可得、已核验公司行动的总回报序列仅用于信号。禁止价格缺行自动补齐。

没有真实数据的本次交付只验证信号实现，不提升策略等级；不得将合成测试视为行情回测或投资收益。
