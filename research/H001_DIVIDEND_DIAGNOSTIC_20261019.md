# Leek · H001 分红感知历史诊断（2026-10-19）

> **研究状态：UNVALIDATED_CA_PROXY。** 下列结果不是可交易的、经过全部数据审计的 ETF 总回报策略业绩；不允许据此自动晋级、实盘下单或加仓。整个过程保持 H001 冻结参数（MA120 + 3 收盘交易日确认），没有根据新结果调参。

## 这轮完成的工程增量

1. 新增 `leek/dividend_proxy.py`：独立于旧价格实验，不覆盖它原来的结果。历史原价仅用于执行代理与盯市；按除息日增量构造前向总回报信号。总回报序列只使用截至当日已经发生的每份分红和已收盘价格，不把后来的分红信息向前填充。
2. 复用 `leek.ledger.Ledger`：权益登记日收盘确认持有数量；除息日记录应收红利，NAV 纳入应收款但不能提前使用它买入；现金红利发放日在**完成当日交易后**转入可支配现金（保守时点假设）。
3. `research/510300_provisional_dividend_events.json`：整理价格实验两段窗口内的 7 次现金分红。2017、2018、2019 两次、2021、2022 的事件日期与金额来自二级数据表，2026 日期和金额有管理人公告转载与上海证券交易所除息公告支持。**事件齐全与否、历史可交易性、原始价格准确性均未通过验收。**
4. 新增 `tests/test_dividend_proxy.py` 和 GitHub Actions 双 Python 版本自动运行；对缺交易日、日期顺序、重复事件、未知数据来源、篡改的历史文件均按 fail-closed 原则阻断。
5. 历史第三方行情在运行时下载、校验精确 Git blob SHA，不进入本仓库。旧纯价格报告仍留在 `research/H001_PRICE_DIAGNOSTIC_20261019.md`，作为独立的可审计失败/变化对照。

## 结果（研究账户 50,000 元）

以下新实验使用固定参数：初始资金 50,000 元，进场参考约 20% 预算，每 100 份取整，收盘信号至下一观察交易日开盘价成交，单笔不利滑点 5bp，佣金 0.02%（最低 5 元），现金闲置零收益，不主动期末平仓。两个样本**独立初始化**，不能拼成连续复利或近五年合格历史。

| 研究窗口 | 策略 | 旧版纯价格诊断 | 本次分红感知净值代理收益 | 本次最大收盘回撤 | 本次已完成往返交易 |
|---|---|---:|---:|---:|---:|
| 2016-09-19—2022-10-14 / 1,474 行 | 零息现金 | 0.000% | 0.000% | 0.000% | 0 |
| 同上 | 一次性约 20% 买入持有 | +2.648% | **+4.469%** | -9.850% | 0 |
| 同上 | MA120（1 日） | +0.469% | **+2.285%** | -8.175% | 30 |
| 同上 | H001（3 日确认） | +3.343% | **+3.893%** | -6.933% | 12 |
| 2025-07-07—2026-07-03 / 241 行 | 零息现金 | 0.000% | 0.000% | 0.000% | 0 |
| 同上 | 一次性约 20% 买入持有 | +0.501% | **+0.993%** | -1.454% | 0 |
| 同上 | MA120（1 日） | -0.640% | **+0.859%** | -1.151% | 2 |
| 同上 | H001（3 日确认） | -0.212% | **-0.282%** | -1.589% | 1 |

在新的计算中，旧窗买入持有得到分红 910.60 元，MA120 得到 480.80 元，H001 得到 470.00 元；新窗分别为 246.00 元、246.00 元、258.30 元。**收益变化不仅来自持仓分红入账，还来自除息后总回报信号改变了进出场时点，因此不能把新旧收益的差额直接理解成“补分红的钱”。**

**新结论与旧结论发生冲突：**
- 旧窗 H001 高于 MA120，但**低于同预算买入持有**（3.893% vs 4.469%）。
- 新窗 H001 **低于 MA120 与买入持有，且收益为负**（-0.282% vs +0.859% / +0.993%）。
- 因分红跨越持仓/平仓边界且本轮尚未落实逐交易归因，新的已平仓**胜率明确留为 null**，不能用旧版纯价格胜率替代。期末未平仓没有强制退出或扣未来卖出成本。

这些不利结果原样保留。两个窗口已被观察与反复诊断，**不是独立样本外证据**。本轮仍不能证明 H001 比原规则或被动持有更好，更不意味着可以可靠地提高下一笔交易胜率。

## 重要的完整性限制

- 公司行动数据依然为 `UNVERIFIED_SECONDARY_CROSSCHECK`，并非完整的官方原始历史分红/基金份额变化证据。代码在输出中强制 `corporate_actions_complete=false`、`eligible_for_automatic_promotion=false`。
- 成交使用日线开盘价和假设费用，未检验真实盘口、停牌、涨跌停、价差、委托成交率、有效证券池和交易规则时点。费用也不是国元证券的实际费率。
- 早期历史日线多数保留两位小数，价格精度可能导致均线触发噪声。两段样本不连续，中间缺数据，后段完整往返交易数量极少。
- 总回报信号是简单前向分红调节模型 `TR[t] = TR[t-1] × (Close[t] + Dividend_ex[t]) / Close[t-1]`，属于研究近似，不是基金管理人认证的收益率序列，也不能直接充当买卖价格。
- 日期只有公告日，不含精确发布时间；**只使用除息日已发生分红来更新总回报**，未在公告当日模拟消息驱动买卖；如未来使用公告消息特征，必须再次验证确切可用时点。
