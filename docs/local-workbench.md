# 本机研究工作台

在 Mac 上双击仓库里的 **打开 Leek.command**。入口会找到本机已有 Python 3.10+，启动服务并请求浏览器打开中文工作台。若系统未拉起终端，使用下方一行启动；若浏览器未出现，点击终端打印的本机链接即可，服务不会因此退出。无需安装 Python 包。首次可点击“运行合成示例”，体验六个虚构交易日的信号、模型成交和结果；结果、历史入口和 JSON 导出始终标为合成数据。

窗口里可以：

- 在“选择一个已完成的历史实验”打开 CA1，按数据与规则、结果与成本、基准、风险与执行、证据分层阅读。每个主要数字解释用途；八组账户与成本完整保留。可导出本页核对结果与固定来源。
- 结果总览默认一起显示盈利、独立研究费用情景、经济结余和最大回撤。点击数字查看共用的定义、期间、单位、成本口径和确切来源。三种汇率情景、固定成交成本翻倍诊断与重新执行各自保留；研究费经济结余不是复投年化。
- 历史阅读在每次打开时核对源码内的固定公开归档。失败即隐藏收益；不会用最近摘要或合成结果补齐。H002/H003 完整结果尚未接入此入口。私人原始输入未接入不妨碍阅读公开派生归档，但不能称为重跑历史或市场真实性认证。
- 阅读截至注明日期的已审公开研究摘要。它是随版本提供的快照，不会自动联网更新，不表示草稿PR已经部署。
- 只读检查当前入口的研究资料，展开查看缺项。代码已具备、资料就绪和历史收益已运行是不同状态。
- 重复体验、刷新查看记录、导出合成结果。每次独立新建目录，失败/损坏记录保留；点击重新体验生成新记录，不覆盖旧输出。

网页“退出工作台”或终端 Ctrl+C 停止服务；下次双击重开。仅关闭浏览器标签页不会停止服务。重复双击会复用同一实例，不启动第二个服务。随机回环端口避免占用固定端口；仅127.0.0.1可访问，没有自启、公开服务、历史收益执行按钮或真实交易接口。

## 本机维护与恢复

终端备用启动：

```sh
# 在候选目录执行，与双击使用同一脚本
./'打开 Leek.command'
python3 -m research.workbench.app
# 不自动开浏览器，适合维护验收
python3 -m research.workbench.app --no-browser
```

如果系统python太旧，可设置`LEEK_PYTHON`指向已有3.10+解释器后使用双击入口脚本。脚本不会安装软件。源码要完整保留；移动整个候选目录可继续使用，内部文件不得单独移动。

可在仓库根创建被git忽略的`.workbench-config.json`，**只在本机保存**已有数据位置（字段均可省略，但显式文件必须为JSON对象；[]、false、null、数字和坏JSON均拒绝）：

```json
{"ca1_private_root":"/absolute/path/to/restored-ca1","h002_data_dir":"/absolute/path/to/reviewed-h002-data","h003_data_dir":"/absolute/path/to/reviewed-h003-data"}
```

双击入口自动读取该文件。终端入口需显式传`--config .workbench-config.json`。更改配置后退出重开。原件只读，沿用`research.cli.preflight`校验；不触发fetch或真实收益run。没有配置不等于整台机器无原件，页面只报告当前入口是否接入。坏配置在启动前拒绝；坏输入在卡片显示核对失败，不显示异常自由文本或绝对路径。修复配置/原件后刷新或重启。原来的CLI `status`退出0只表示状态收集，不是研究成功；本界面逐项读取preflight状态。

默认状态在仓库`.workbench/`（git忽略，owner-only）；`runs/`保存合成记录。运行中断的记录显示需检查，可重新体验。损坏/旧源码绑定的结果不会显示为新成功。不自动修复、删除或续跑历史记录。进程退出后再次启动可替换旧的临时实例指针，不覆盖`runs/`。已有实例暂不可联系时拒绝另开，提示稍后重试/关闭原终端。可使用`--state-dir NEW_PRIVATE_DIRECTORY`进行隔离验收；不要复用未知/他人目录。

退出后移走这个候选checkout及其自身`.workbench/`即可撤回，保留合成记录时先复制整个目录。不要删除别的研究归档或已验收部署。此候选不覆盖原main部署、不修改全局安全配置。

## 验证边界

```sh
python3 -m unittest discover -s tests -p test_workbench.py -v
```

测试含真实loopback HTTP请求，受限沙箱可能拒绝监听，不能将其标为通过。网页来源检查、一次性实例内表单token、Host约束、无任意文件路由；静态页面不加载远端脚本、字体或资源。点击“查看公开研究”才会由浏览器访问GitHub。这里不声称抵抗拥有同一用户文件修改权限的攻击者。合成输出双文件/hash核对属于完整性检查，不能证明市场来源或投资能力。

当前不提供数据上传、参数编辑、常驻调度、券商、模型调用或真实回测。这些不是使用示例的前提；若要运行新历史研究，继续使用现有登记与数据校验流程，不能把合成成功当放行。

分层职责、只读接口、证据边界与后续接入条件见[分层系统说明](layered-research-system.md)。本次只是 CA1 的归档阅读增量，各层尚未形成通用交易流水线。

本机运行验证使用已有 Python3.12 与 macOS Bash3.2；GitHub CI另验证Python3.10/3.12，未声称3.11解释器实跑。Finder图形会话双击仍需实际确认，系统open返回0不等于窗口已显示。直接脚本启动、无配置首开及浏览器失败后的可点击本机链接为独立路径，不需修改文件关联或安全设置。
