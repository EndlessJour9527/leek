# Leek 量化研究目标与阶段验收

## 第一原则与每轮取舍

目标是在可执行、成本后且风险可承受的条件下追求长期资本增长，不承诺收益或回本。研究与真实交易分开；代码按冻结规则执行，LLM只辅助调查与提出反证，不能充当盈利证明或批准仓位。**不连接券商、不提交真实订单、不擅自扩大账户风险、不自动将新策略上线。** 本文是既有研究取舍准则，不新增审批层，也不改已冻结策略、账户及历史结论。

1. **机制与待证假设**：研究先说明预期收益的经济或行为机制、谁付费或承担何种风险，以及竞争为何未消除它。证据不足写“待证”，不事后编故事。相关性可用于预测研究但不冒称因果；可承受的风险溢价也有价值，不要求每项都是alpha。借鉴开源时记录版本、许可证及移植差异。
2. **最简单可比对照**：先比较现金、买持，按问题补静态配置或暴露适配基准；固定输入、窗口和成本，账户各自记账。报告实际暴露差异，不把相同目标权重当作风险匹配，不把独立账户相加。复杂模块必须相对简单版本说明可测增量及研究、维护和运行成本。
3. **当时能知道、能执行什么**：固定信息可得时点、原始价格/公司行动单位、成本、资金与整手约束，检查容量、尾部损失和未成交；未知保留缺口。规则由程序执行，核心现金/股份/分红守恒与时点回归保留。已看历史只能是开发数据，重试或换名不能恢复“未见”资格。
4. **事前可证伪**：查看对应评估结果前写反证、失败/保留标准、停止阈值和评估成本。结果区分实现缺陷、证据不足与经济机制失败；一次失败不自动证明永久无效，也不能事后挑赢家或修改原阈值。保留失败、拒单、未平仓和所有尝试记录。
5. **按增量剪枝**：先查现有登记与可信检查；未变项复用，只测变更影响及相关守恒/时点回归。不重复旧回测冒充新证据。无可测增量或成本过高的方向降优先级/归档，不删除历史。问题按受影响输入和实验传播；旧十账户共同T0、LLM验收不是独立确定性研究的总开关，原冻结协议自身要求仍保留。
6. **最短交付**：复用已有引擎、账本、基准和[每日报告模板](multi-trader-research.md#每日报告)，记录本轮变化、证据、状态和下一最小问题；可标待证或暂无增量，不强迫每个问题二元放行。文档完善不算收益进展。代码在独立分支评审，发布/合并遵循已有授权，不因本准则自动执行。

原10席位是历史组织登记，不是必须开发10策略或每天重跑10次的配额。按新增信息和成本选择工作；已有席位/尝试记录见 `research/trader_team.json`，组织背景见[每日多交易员研究](multi-trader-research.md)。每席位每轮至多一个预登记新候选，不刷参数网格；既有阶段预算如下，不因剪枝重置。

每阶段最多8个新增策略候选，**这是全团队共享预算，不是每席位8个**；失败与放弃尝试同样计数。达到预算仍无候选通过时，输出失败复盘、数据/假设问题与下一阶段协议，不静默放宽门槛或宣称已经收敛。此预算是控制多重尝试的流程约束，不是保证8次内找到优势。

## 何时认为达到“满意的阶段”
以下是研究验收门槛，不是个人账户风险承诺，也不是统计显著性的替代品。

### M1：可复现的真实历史实验
同一快照可重算相同账本；信号无未来泄漏；分红、手续费、浮盈亏和资金守恒；现金/被动基准、成本压力和逐笔日志齐全。数据来源及缺口明确。当前PR5建立了单ETF条件回测，但第二价格源和完整公司行动认证仍未完成。

### M2：值得进入前向验证的候选
- 先过预登记研发筛选；再用未参与筛选的数据独立检验。2020—2025已经消费，不可改名叫封存样本；此前看过的2026窗口也不能复用为未见证据。
- 至少3个有实质差异的资产/市场暴露，避免把高度重叠ETF当成三份独立证据；明确固定证券池和样本选择偏差。
- 使用同风险预算的基准，报告平均暴露差异；收益/风险改善指标必须在查看验证结果前确定。
- 独立验证的成本后净收益与每笔净期望为正，压力成本下不转为负；最大回撤不超过事前选定的风险可比基准。任何不满足均需解释和保留，不能改用胜率替代。
- 至少50笔已平仓研究样本才讨论胜率稳定性；这只是最低信息量，不证明独立或稳定。应报告时间相关性、有效样本、区间估计和试验次数，不把Wilson区间当下一笔概率。
- 检查不同阶段、邻近参数敏感性和单笔盈利集中度；敏感性测试只诊断，不能据此换成最好参数继续占用原封存集。

### M3：可部署的模拟交易候选
冻结模型后至少60个真实新交易日、且累计至少20笔已平仓前向样本；记录事前信号、实际可用数据、未成交及净值，不追写过去信号。核对重启、幂等、对账和异常阻断。满足前向门槛只允许模拟部署评审，不自动允许实盘。

阶段目标是找到经上述证据支持的候选，或清楚判定当前策略族无优势。不存在保证盈利或永远不失效的“最终模型”。
