# Leek 量化研究目标与阶段验收

## Goal
持续调试可复现的量化交易模型，吸收开源金融项目的策略思想、风险控制和工程经验，在真实历史数据上检验，并积累前向模拟证据。目标是成本后交易质量改善，不是承诺回本、持续提高胜率、无限调参直到历史盈利。

研究推进和真实交易分开。代码可自动测试、生成报告；不连接券商、不提交真实订单、不擅自扩大账户风险、不自动将新策略上线。主分支只通过评审PR改变。

## 每轮固定流程
1. 读取最新仓库、历史实验登记和失败原因；不要重复已完成工作。
2. 研究原项目源码/文档，记录精确版本、许可证、市场假设及移植差异。
3. 预登记一个新假设和筛选标准，再查看这个候选的成绩。每轮最多一个新增候选，不进行参数网格刷分。
4. 固定真实输入快照与数据等级；相同账户/时点/费用重跑旧基线。数据冲突阻断，网络不可用只能以明确研究降级继续，不能替换为合成行情。
5. 跑因果测试、账本守恒、逐笔归因、基准与压力费用、年度/市场阶段和机会成本分析。拒单、期末未平仓及失败结果都保留。
6. 按事前标准输出 REJECTED、NEEDS_MORE_EVIDENCE 或 RESEARCH_SCREEN_PASS。研发通过不等于样本外通过。
7. 将代码、输入/配置指纹、报告和CI记录提交独立分支，创建PR。新机制和执行口径改变必须分别登记。

每阶段最多8个新增策略候选；达到预算仍无候选通过时，输出失败复盘、数据/假设问题与下一阶段协议，不静默放宽门槛或宣称已经收敛。此预算是控制多重尝试的流程约束，不是保证8次内找到优势。

## 何时认为达到“满意的阶段”
以下是研究验收门槛，不是个人账户风险承诺，也不是统计显著性的替代品。

### M1：可复现的真实历史实验
同一快照可重算相同账本；信号无未来泄漏；分红、手续费、浮盈亏和资金守恒；现金/被动基准、成本压力和逐笔日志齐全。数据来源及缺口明确。当前PR5建立了单ETF条件回测，但第二价格源和完整公司行动认证仍未完成。

### M2：值得进入前向验证的候选
- 先过预登记研发筛选；再用未参与筛选的数据独立检验。2020—2025已经消费，不可改名叫封存样本；此前看过的2026窗口也不能复用为未见证据。
- 至少3个有实质差异的资产/市场暴露，避免把高度重叠ETF当成三份独立证据；明确固定证券池和样本选择偏差。
- 使用同风险预算的基准，报告平均暴露差异；收益/风险改善指标必须在查看验证结果前确定。
- 独立验证的成本后净收益与每笔净期望为正，压力成本下不转为负；最大回撤不超过事前选定的风险可比基准。任何不满足均需解释和保留，不能改用胜率替代。
- 至少50笔已平仓研究样本才讨论胜率稳定性；这只是最低信息量，不证明独立或稳定。应报告时间相关性、有效样本、区间估计和试验次数，不把Wilson区间当下一笔概率。
- 检查不同阶段、邻近参数敏感性和单笔盈利集中度；敏感性测试只诊断，不能据此换成最好参数继续占用原封存集。

### M3：可部署的模拟交易候选
冻结模型后至少60个真实新交易日、且累计至少20笔已平仓前向样本；记录事前信号、实际可用数据、未成交及净值，不追写过去信号。核对重启、幂等、对账和异常阻断。满足前向门槛只允许模拟部署评审，不自动允许实盘。

阶段目标是找到经上述证据支持的候选，或清楚判定当前策略族无优势。不存在保证盈利或永远不失效的“最终模型”。
